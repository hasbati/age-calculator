# Hasbati Age Calculator (PHP)

A simple and reliable PHP utility for calculating a person's exact age in years, months, and days based on their date of birth.

## Usage

```php
require 'vendor/autoload.php';

$age = AgeCalculator::calculate('1990-05-15');
print_r($age);
```
